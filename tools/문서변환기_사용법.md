# 문서 변환기 (LibreOffice 기반) — 사용법

API 키 없이, 인터넷 없이 내 PC에서 HWP·DOC·PPT·PDF 등을 서로 변환하는 도구입니다.
무료 프로그램 **LibreOffice**의 변환 엔진을 사용합니다.

## 1. 준비 (처음 한 번만)

1. https://ko.libreoffice.org/download 에서 LibreOffice를 내려받아 설치합니다. (무료)
2. 설치가 끝나면 아래 변환기 파일을 사용할 수 있습니다.

## 2. Windows 사용법

1. `문서변환기_윈도우.bat` 파일을 바탕화면 등 편한 곳에 둡니다.
2. 변환할 파일(들)을 **이 .bat 아이콘 위로 끌어다 놓습니다.**
3. 검은 창이 열리면 원하는 출력 형식 번호(1=PDF, 2=DOCX …)를 입력하고 Enter.
4. 변환된 파일은 원본이 있던 폴더의 **`converted`** 폴더에 저장됩니다.

## 3. Mac 사용법

1. `문서변환기_맥.command` 를 더블클릭합니다.
   - 처음엔 "확인되지 않은 개발자" 경고가 날 수 있습니다. → 파일을 **우클릭 → 열기 → 열기**로 실행하세요.
   - 실행 권한이 없다는 오류가 나면 터미널에서 `chmod +x 문서변환기_맥.command` 한 번 실행.
2. 터미널 창이 열리면 변환할 파일을 창으로 끌어다 놓고 Enter.
3. 출력 형식 번호 입력 → 원본 폴더의 `converted` 폴더에 저장됩니다.

## 지원 형식

- **잘 됨(양방향):** DOCX ⇄ PDF, PPTX ⇄ PDF, XLSX ⇄ PDF, ODT, RTF, TXT 등
- **HWP:** 기본 LibreOffice는 구버전 HWP(한/글 5.0) 열기를 일부 지원합니다.
  최신 HWP/HWPX나 더 정확한 변환이 필요하면 LibreOffice 확장
  **"H2Orestart"** (https://extensions.libreoffice.org 에서 검색) 를 설치하세요.
- **PDF → 편집형식(DOCX 등):** 가능하지만 원본이 스캔 이미지면 결과 품질이 낮을 수 있습니다.

## 자주 묻는 질문

- **"soffice를 찾을 수 없다"** → LibreOffice 설치 여부와 설치 경로를 확인하세요.
- **변환이 실패** → 그 형식 조합을 LibreOffice가 지원하지 않는 경우입니다. 다른 출력 형식을 시도하세요.
- **파일이 열려 있으면** 변환이 실패할 수 있으니 원본을 닫고 실행하세요.
