👀 눈산책

화면 캡처

버튼을 누르면 공유 창이 뜹니다. 여기서 특정 창을 고르면 창 캡처, 전체 화면을 고르면 전체 캡처예요. 캡처한 뒤 "영역 잘라내기"로 원하는 부분만 드래그해 영역 캡처처럼 쓸 수 있습니다.

※ 캡처 후 잘라내기·저장, PDF/압축으로 전달 가능

화면 공유가 거부되었어요 — 확인하세요

1) Mac 사용자: 시스템 설정 → 개인정보 보호 및 보안 → 화면 기록에서 크롬/엣지를 켜고 브라우저를 완전히 껐다 켜세요.
2) 공유 선택 창에서 취소를 누르지 않았는지 확인하세요.
3) 파일을 그냥 더블클릭(file://)하면 막힐 수 있어요. Chrome 또는 Edge로 열어보세요.
4) 그래도 안 되면 화면을 직접 캡처(Windows: Win+Shift+S, Mac: ⌘+Shift+4)해 저장한 뒤, 위 "이미지 파일 열기" 버튼으로 불러와 압축·PDF로 이어서 쓰세요.

            예: HWP→PDF, PDF→DOCX, PPTX→PDF 등. 지원되지 않는 조합은 변환 시 오류로 안내됩니다.

            날짜를 클릭하면 일정을 추가하거나 일기를 쓸 수 있어요. 파란 점=일정, 📔=일기

            🖼️ 이미지로 일정 추가

            시간표·안내문 등의 사진을 올리면 글자를 인식(OCR)해 날짜·시간이 있는 줄을 일정 후보로 만들어 드려요. (한글+영문)

            🔗 가져오기 / 내보내기 · 구글 캘린더

            · CSV 형식: 날짜,시간,제목 (예: 2026-03-15,14:00,병원 예약). 엑셀에서 편집 가능.
            · 구글 캘린더에 넣기: ICS 파일을 내보낸 뒤 구글 캘린더 → 설정 → 가져오기에서 업로드하면 모든 일정이 등록됩니다. 개별 일정은 날짜를 클릭해 "구글 캘린더에 추가" 링크로도 바로 넣을 수 있어요.

              ✏️ 오늘의 메모

              기분 이모티콘을 고르고 한 줄만 남겨보세요. 남긴 메모는 아래에 쌓입니다.

              📄 문서 변환 API (CloudConvert)

              HWP·DOC·PPT ↔ PDF 온라인 변환에 사용합니다. 무료로 하루 약 10건 변환할 수 있어요.
              발급 방법
              ① cloudconvert.com 무료 가입 후 로그인
              ② 우측 상단 프로필 → Dashboard 접속
              ③ 왼쪽 메뉴 API → API Keys → Create New API Key 클릭
              ④ 권한(Scopes)에서 task.read, task.write를 체크하고 생성
              ⑤ 만들어진 키를 복사해 아래에 붙여넣고 저장

              🔒 키는 이 브라우저에만 저장되며 서버로 전송되지 않습니다. 공용 PC에서는 저장하지 마세요.

              🖥️ LibreOffice 설치 (API 없이 변환)

              인터넷·API 키 없이 내 PC에서 변환하고 싶다면 무료 프로그램 LibreOffice를 설치하세요. 함께 드린 문서변환기(윈도우 .bat / 맥 .command) 파일이 이 프로그램을 사용합니다.
              설치 방법
              ① ko.libreoffice.org 다운로드 페이지 접속
              ② 내 운영체제(Windows/Mac)용 설치 파일을 내려받아 실행
              ③ 안내대로 설치 완료
              ④ 변환할 파일을 "문서변환기_윈도우.bat"(맥은 .command) 위로 끌어다 놓고 형식 선택
              ⑤ 원본 폴더의 converted 폴더에 결과가 저장됩니다
              ※ 최신 HWP 변환은 LibreOffice 확장 H2Orestart를 추가 설치하면 더 정확합니다.

              🖼️ 이미지 분석 (일정 자동 인식) 설정

              일정표의 "이미지로 일정 추가"에서 글자를 인식하는 방식을 고릅니다.

              OCR API 키 발급 방법 (OCR.space · 무료 월 25,000건)
              ① ocr.space/ocrapi/freekey 접속
              ② 이메일 입력 후 Subscribe to Free plan 클릭
              ③ 메일함으로 온 API 키를 복사해 아래에 붙여넣고 저장

              🔒 모든 키는 이 브라우저에만 저장됩니다.
